# Cocktails

## Une interface utilisateur pour homebrew

## Etape Analyse

Cocktails sera une app écrite en C# et Avalonia.
Le but sera de d'utiliser homebrew via une interface GUI moderne et élégante.

L'application proposera les fonctionnalités de base telles que :
- gestion des packages installés
- recherche de packages 
- installation de packages
- upgrade des packages installés 
- désinstallation de packages installés.

Dans une deuxième phase, on implémentera des fonctionnalités avancées telles que :
- monitoring actif des packages pour détecter les updates disponibles
